# 回答标注来源指引

当用户要求可追溯的回答 (给出处 / 标来源 / 引用出自哪), 或问题涉及需要溯源的事实, 按以下规范作答。

## 标注规范

1. 每引用一条来自工具 (如 `rag_query`) 返回的信息, 就在该句末尾用 `[来源: <source 路径> #<chunk 序号>]` 标注。
2. source 路径取工具返回结果里每个 hit 的 `source` 字段 (通常是绝对路径), 只保留文件名部分给用户看即可, 完整路径太长。
3. 一条回答用了多个 chunk, 每处分别标, 不要笼统在结尾堆一串。

## 没有来源就别编

若某句话不是来自任何工具返回的内容 (你的推理/常识), **不要**给它编造来源标注。宁可明说"这句是我的推断, 无来源", 也不假装有出处。

## 用户没要求时

用户没明确要来源时, 也可以主动标 —— 但保持克制, 别让标注淹没正文。一句话一个来源足矣。
